# Worshipd

A web based game where the goal is to guess the christain contemporary music based on limited information given.

## Features

- Web Game: Accessing the game is as easy are going to a website
- Song Clips: All music clips are hand editted and pick out from song from my playlist
- Song List: Webpage with all the songs in rotation in the game with their name, artist and links to it
- Range of Difficulty: Includes 3 difficulties for a range of skill.

## Getting Started

It's very simple, just go to **https://worshipd.duckyccm.me/**

It is recomended to use headphones and to allow auto play of audio if asked.

## How To Play

There are 3 webpages:

- Play (main game page)
- Song List (The list of song that are in rotation in the game)
- Info (Information about the game, how it work, how to play and is basically an beefed up journal of the entire project)

The 'Play' webpage is the main page where the actual game is. This is where you enter and start playing the game. To play you need to first select your difficulty. There are 3 difficulties:

- Casual: The name of the song is mentioned in the clip
- Familiar: Lyrics from the song is mentioned in the clip
- Worshiper: Only the instrument is heard in the clip (tis can vary between songs)

I would highly recommend 'Casual' mode if you are not familiar with christain songs.

Next, you need to pick the amount of songs you want to guess. You can choose between 1, 3 and 5 songs to guess in a game.

After choosing both the difficulty and song quantity, you can finally start playing the game. There are 6 thing you'll see.

- Difficulty: The difficulty you selected
- Strikes: The amount of times you can guess wrong before you lose
- Song Status Indicator: Shows you the statuus of that specific song (corrct, wrong, skipped or selected)
- Song Controls: Controls for the song audio (play, repeat, skip, submit)
- Song Progress: Indicates the length and audio left of the song's audio
- Search Bar/Drop Down Menu: Search bar and drop down menu to find the song

The audio should play instantly. In case it doesn't, press either the repeat button or the play button. The aim of the game is to guess the song based on the audio given.
