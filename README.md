# Worshipd

A web based game where the goal is to guess the christain contemporary music based on limited information given.

## Features

- Web Game: Accessing the game is as easy are going to a website
- Song Clips: All music clips are hand editted and pick out from song from my playlist
- Song List: Webpage with all the songs in rotation in the game with their name, artist and links to it
- Range of Difficulty: Includes 3 difficulties for a range of skill.

There are 3 webpages:
- Play (main game page)
- Song List (The list of song that are in rotation in the game)
